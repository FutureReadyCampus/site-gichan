01 · CORE STRENGTH

어려운 개념을
가장 쉬운 직관까지 풀어냅니다

선형회귀를 "면적 → 가격"이라는 일차함수로, 어텐션을 행렬 직관으로, 나눗셈을 평등 분배로 — 결과물을 던지기 전에 왜 그렇게 동작하는지부터 설계합니다.

스스로를 AI Constructionist라고 부릅니다. 정답을 알려주는 사람이 아니라, Lifelong Kindergarten(MIT 미디어랩, Mitchel Resnick)이 말하는 환경조성자에 가깝습니다 — 직접 만지고 실패하며 배우도록 로드맵·시각화·실습 환경을 먼저 설계합니다.

이 사이트는 AI를 가르치는 이기찬에 집중합니다. 직접 짠 코드와 인프라는 bit-habit.com(개발자 포트폴리오)에서 확인할 수 있습니다.

04

인프라·네트워크 기초

웹사이트나 앱이 인터넷에서 열리려면 사용자의 요청이 알맞은 서비스까지 찾아가고 안전한 연결을 거쳐야 합니다. 저는 서버 한 대에 20여 개 서비스를 올린 k3s 클러스터를 직접 설계하고 운영합니다. 수업에서는 주소를 입력했을 때 요청이 어느 길로 이동하는지부터 설명합니다. 이어서 HTTPS 자물쇠를 만드는 인증서가 왜 필요한지, 새 버전을 올릴 때 서비스가 어떻게 바뀌는지 실제 화면으로 보여줍니다. 어려운 명령어를 외우기보다 라우팅·인증서·배포가 하나의 서비스 안에서 어떻게 이어지는지 이해하도록 돕습니다.

Kubernetes(k3s) · Traefik · cert-manager · GitHub Actions
